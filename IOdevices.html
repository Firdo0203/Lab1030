Main I/O devices Memory Transistors

Input and output devices developed from earlier ideas about separating calculations, storing information, and processing data. As computers became more advanced, they needed better ways to receive information from users and communicate the results of their calculations. Today, computers use many different input and output devices that work with the CPU. Input devices, such as keyboards and mice, allow users to provide information and commands to the computer. Output devices, such as monitors and printers, allow the computer to display and print the result, as well as connect to many other computers via internet. Many other devices can also perform input, output, or both functions.
