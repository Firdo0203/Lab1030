Memory

Main I/O devices Memory Transistors

Charles Babbage constructed his difference machine, which could mechanically take input and produce results. This was an important early step toward machines being able to process information automatically. Around the 1940’s first computers had only few bytes of memory. They used vacuum tubes and early technologies to perform calculations and temporarily hold numerical information. After years of inventions and experimentation, computer memory developed through technologies such as magnetic-core memory, which could store information in the form of bits and provide computers with several kilobytes of memory. As technology continued to improve, semiconductor memory replaced magnetic cores and allowed computers to store and access much larger amounts of information.

Today’s computer memory is much more advanced and runs through different memory systems that are specifically designed to run through memory fast. In example of RAM today a small to moderate functioning computer has about 4-16 gigabytes of RAM, just to process information. Stored memory is lot bigger with billions – trillions of bytes of storage. This allows computers to run faster and provide results more efficiently.
